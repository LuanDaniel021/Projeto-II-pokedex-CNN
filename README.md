
# 📊 Pokédex com Redes Neurais Convolucionais (CNN)

Projeto acadêmico com objetivo de desenvolver uma Pokédex inteligente capaz de identificar Pokémons a partir de imagens utilizando Redes Neurais Convolucionais (CNNs).


---

## 🚀 Objetivo

Criar um modelo de classificação de imagens que:

- Identifique automaticamente Pokémons a partir de imagens

- Permita upload de imagens pelo usuário

Retorne:

- Nome do Pokémon

- Descrição do Pokémon


Simulando o funcionamento de uma Pokédex real.


---

## 🧠 Tecnologias

- Python
- CustomTkinter
- TkinterDnD
